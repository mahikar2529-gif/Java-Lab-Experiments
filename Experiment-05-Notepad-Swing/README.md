# Experiment 5: Notepad Features using Swing

## Aim
To build a mini Notepad with file and edit operations using Swing.

## Question
> Write a program to create some of the features of Notepad. Use Swings for designing this application.

## Concepts Used
- JFrame, JTextArea, JScrollPane
- JMenuBar / JMenuItem
- JFileChooser, file I/O

## Files
- `Notepad.java`
- `Question.md`
- `Output.txt`

## How to Compile and Run
```bash
javac Notepad.java
java Notepad
```
