# Experiment 11: Form with Name and Password (Applet container)

## Aim
To create the Name/Password form that will be reused for database operations in Experiment 12.

## Question
> Create a form containing fields name and password respectively, using Applet as a container.

## Concepts Used
- Applet as container
- GridLayout
- ActionListener

## Files
- `LoginApplet.java`
- `LoginApplet.html`
- `Question.md`
- `Output.txt`

## How to Compile and Run
```bash
javac LoginApplet.java
java LoginApplet        # runs in a Frame
# or, on JDK 8 or earlier:
appletviewer LoginApplet.html
```
