# Experiment 2: Animated String Applet (Multithreading)

## Aim
To animate a string across an Applet using a separate thread.

## Question
> Write a program to animate a string on Applet. Use the concept of Multithreading.

## Concepts Used
- Applet life cycle
- Runnable / Thread
- repaint()

## Files
- `AnimatedString.java`
- `AnimatedString.html`
- `Question.md`
- `Output.txt`

## How to Compile and Run
```bash
javac AnimatedString.java
java AnimatedString        # runs in a Frame (works on modern JDKs)
# or, on JDK 8 or earlier:
appletviewer AnimatedString.html
```
