# Experiment 7: Form with Name and Password (Applet)

## Aim
To create a form with Name and Password fields inside an Applet.

## Question
> Create a form containing fields name and password respectively. Use Applet as a container.

## Concepts Used
- Applet as container
- TextField with echo char
- Event handling

## Files
- `LoginForm.java`
- `LoginForm.html`
- `Question.md`
- `Output.txt`

## How to Compile and Run
```bash
javac LoginForm.java
java LoginForm        # runs in a Frame
# or, on JDK 8 or earlier:
appletviewer LoginForm.html
```
